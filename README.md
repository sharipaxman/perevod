# English Lesson Copilot

Десктопное приложение для онлайн-уроков английского. Оно слушает **системный звук**, распознаёт речь преподавателя, показывает перевод и предлагает три коротких варианта ответа на английском. История сохраняется локально.

## Возможности

- захват системного аудио из звонка или видео;
- распознавание английской речи;
- перевод на выбранный язык;
- 3 варианта ответа в дружелюбном, кратком или формальном стиле;
- локальная история последних 100 фраз;
- копирование ответа одним кликом;
- контекст урока: предыдущие фразы, ответы и снимки экрана;
- снимок экрана можно прикрепить к следующей фразе горячей клавишей;
- ключ API хранится только в `localStorage` на компьютере пользователя.

## Запуск

Требуются Node.js 20+, Python 3.11+ и Inception Labs API key для OpenAI-compatible API `https://api.inceptionlabs.ai/v1`.

```bash
npm install
python -m pip install -r requirements.txt
npm start
```

1. Вставьте Inception Labs API key в левую панель.
2. Нажмите **«Начать слушать»**.
3. В системном окне выберите экран и обязательно разрешите передачу системного звука.
4. Запустите урок. Новая карточка появляется примерно каждые 6–10 секунд, если в аудио есть речь.

## Модель

Перевод и варианты ответа генерирует **`mercury-2.5`** через Inception Labs OpenAI-compatible API (`https://api.inceptionlabs.ai/v1`). Заменить модель или базовый URL можно переменными окружения без правки кода:

```bash
set ASSIST_MODEL=mercury-2.5                 # Windows
set INCEPTION_API_BASE_URL=https://api.inceptionlabs.ai/v1

export ASSIST_MODEL=mercury-2.5              # macOS/Linux
export INCEPTION_API_BASE_URL=https://api.inceptionlabs.ai/v1
```

Уровень рассуждений по умолчанию `none` (поле `reasoning_effort` не отправляется ради минимальной задержки на уроке), меняется через `ASSIST_REASONING_EFFORT`. Если провайдер не принимает поле `reasoning_effort` или `response_format`, запрос автоматически повторяется без неподдерживаемого поля.

## Горячие клавиши

- `Ctrl+Shift+S` — сделать снимок экрана и добавить его к следующей распознанной фразе;
- `Ctrl+Shift+C` — очистить контекст модели, не удаляя историю;
- `Ctrl+Shift+H` — очистить локальную историю.

## Если карточки перестали появляться

- Под кнопками есть **индикатор уровня звука**. Полоска не двигается → системный звук не приходит: остановите захват и запустите заново, обязательно отметив «Поделиться звуком системы» / «Share system audio». Через 15 секунд полной тишины приложение само покажет предупреждение.
- Фраза отправляется на распознавание после паузы ~0,9 с или через 14 с непрерывной речи. Кнопка **«Обрезать»** отправляет текущий кусок немедленно.
- Ошибка вида `'charmap' codec can't encode characters` означала, что Python выводил кириллицу в кодировке Windows (cp1251/cp866). Исправлено: приложение запускает Python с `PYTHONUTF8=1`, а `transcriber.py` пишет JSON в ASCII-escape.
- Другую модель Whisper можно выбрать переменной `WHISPER_MODEL` (`tiny`, `base`, `small`, `medium`), интерпретатор — через `PYTHON_EXECUTABLE`.

## Ограничения платформ

- **Windows:** loopback-аудио обычно работает сразу.
- **macOS:** дайте приложению разрешения `Screen Recording` и `Microphone` в System Settings. На некоторых версиях macOS захват системного аудио требует виртуальный аудиодрайвер (например, BlackHole).
- **Linux:** требуется PipeWire и разрешение на захват экрана/аудио.

## Приватность и стоимость

Распознавание аудио выполняется локально через `faster-whisper`. При первом запуске модель Whisper `base` будет скачана с Hugging Face. В Inception Labs отправляется только распознанный текст для перевода и вариантов ответа. Репозиторий не содержит API-ключей; не добавляйте их в код. Стоимость зависит от выбранной текстовой модели и тарифов Inception Labs.

## Стек

Electron, Web Media Capture API, Python `faster-whisper` и Inception Labs OpenAI-compatible Chat Completions API.
